# 💼 Ashish Srinivas — Developer Portfolio

Welcome to my personal developer portfolio built using **React.js**,
This portfolio highlights my journey as a **Data Scientist & Full Stack Developer**, showcasing my projects, skills, achievements, and experience.

---

## 🚀 Features

- 🎯 Dynamic React-based portfolio  
- 💻 Skills and Technology Stack section  
- 📊 Work Experience & Projects display  
- 🧠 Education and Achievements timeline  
- 🐙 Integrated GitHub Profile and Repositories  
- 📝 Medium Blog integration (optional)  
- 📬 Contact section with social links  
- 🎨 Fully customizable via `portfolio.js`  
- 🌐 Responsive and mobile-friendly UI  

---

## 🧩 Tech Stack

- **Frontend:** React.js, SCSS, HTML5, CSS3  
- **Animations:** React Reveal, Lottie  
- **Icons:** Font Awesome / React Icons  
- **Version Control:** Git & GitHub  
- **Deployment:** Netlify / GitHub Pages
